# Yarn

Premium handmade crochet e-commerce frontend.

## Stack

- React + Vite + TypeScript
- GSAP + ScrollTrigger
- Lenis smooth scroll
- React Router
- Lucide React
- Single stylesheet: `src/styles.css`

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
